# SimPlot Android 开发文档

> 版本：v1.0（2026-08-10）
> 依据：SimPlot2 Windows 版反编译资料（`decompile-win/`，未 strip 全符号 + 563 个函数反汇编 + 4 份伪代码文档）+ 官方 2.3.9 真实存档（Iron Bottom Sound）+ 安卓源码静态审阅。
> 配套审核底稿：`docs/review/findings-engine.md`（运动/回合/编队）、`docs/review/findings-codec.md`（存档/编解码）、`docs/review/findings-render-ui.md`（绘制/UI）。本文档是汇总与决策层，细节证据看底稿。

## 1. 项目定位与目标

将桌面海战兵棋绘图工具 **SimPlot2**（Xojo 编写，Harpoon/鱼叉规则辅助）移植到 Android（Kotlin + Jetpack Compose），目标：

1. **存档互通**：与桌面版 `Scenarios/` 目录四文件（`Referee.json` + `Blue.SpScn` + `Red.SpScn` + `player_settings.json`）字节级兼容；
2. **行为一致**：回合推进、移动、编队、感知迷雾与桌面版语义一致（鱼叉纸质规则扩展为有意增强，见 §6.4）；
3. **触屏适配**：手势缩放/平移/点选/长按编辑。

当前版本 0.4.9。**审阅结论：核心坐标/序列化/回合状态机骨架正确，但存在 1 个 P0（ID 计数器不维护，桌面续编必撞号）和一批 P1 兼容性/行为缺陷，建议按 §8 路线图修复后再发 1.0。**

## 2. 桌面版参考架构（反编译确认）

Xojo 编译，115 个类。关键分层：

```
WindowMain（CanvasMap 画布 + 右键菜单）
 ├─ Game.Unit.CUnit → CMovableUnit → CAirUnit/CSurfaceUnit/CSubsurfaceUnit/CVehicle
 │                    CInstallation/CLandFormation/CReferencePoint/CSonobuoy
 ├─ Game.File.Referee（SaveFile→SaveScenario/SaveTime/SaveTurns/SaveUnits/SaveObjects/SaveFormations）
 ├─ Game.WayPoint.CWayPoint（CreateWaypoint/RecalcWaypoints/CalcArriveTime）
 ├─ Formations.cFormation（RelativeToCompass/Column/RelativeToCourse 三模式）
 ├─ Game.Perception.CPerception + Game.PassiveBearings.CBearing（迷雾/被动方位）
 ├─ Game.RangeGraphics.CArc（传感器/武器弧）
 ├─ Game.SymbolGenerator.*（NTDS/CWS/WW2 符号 + SpeedLeaders + TrackHistory + TextTags）
 └─ NewMap.* / MercatorPolygon / MercatorRaster（两套矢量地图 + 光栅地图）
```

核心公式（asm 实测）：

| 公式 | 桌面实现 | 出处 |
|---|---|---|
| 位移矢量 | `dX=speed·Sin(course)，dY=speed·Cos(course)`（0=北顺时针） | CalcMoveVector @0x1406d3bf0 |
| 移动距离 | `速度×时间`（整回合/分钟/秒三分支） | CalcDistanceToMove @0x1406d3720 |
| **方位角** | **`ATan2(Δy, Δx)` → 度 → 负+360（数学角，0=东逆时针）** | CalcBearing @0x1405a3a20（asm 已核实参数序 xmm0=dy, xmm1=dx） |
| 新位置 | `ref + dist×(Sin bearing, Cos bearing)` | PushCalcPosition @0x1409f74a0 |
| 到达时间 | `当前时间 + 距离/速度`（天/时/分/秒逐级分解） | CalcArriveTime @0x14072ee60 |
| 编队旋转 | 成员**实际偏移**按航向角旋转矩阵，同步 Course/Speed | MoveCourseFormation @0x140582170 |
| 高度/深度 | 按 Ascent/Descent 速率趋近目标，**单回合上限 180** | ChangeAltitude @0x1406c9510 |

## 4. 数据格式规范（已验证 ✅ / 有缺陷 ❌）

### 4.1 数值编码（✅ 已与官方存档一致）

| 字段 | 编码 | 备注 |
|---|---|---|
| X / Y | 海里 × 100000（Long，Y 北为正） | 例 `-400000` = -4nm |
| Speed / Course | 节/度 × 1000 | 例 `15000` = 15 节 |
| Altitude / Depth | 米，**原样无定点** | 曾误写 ×1000，已修正 |
| Range | 海里整数，`-100000` = 无限制 | |
| FormationBearing | 度 × 1000 | |
| FormationDistance | 文件单位（同 X/Y） | |

### 4.2 SpScn 混淆（✅ 字节级一致）

明文 JSON → 尾部追加 `\x0c\t` → 每字节 +1。`.json` 明文不混淆（尾部 `\r\n`，见决策项 D3）。

### 4.3 序列化缺陷（❌ 需修）

- **P0-C1：`Scenario.LastId / CurrentTrackNumber / CurrentPlayerTrackNumber` 从不写回。** 安卓新建/复制单位用"现有单位 max+1"本地计算，存档计数器不动 → 桌面版打开续建单位时 `GetIdNumber` 撞号（数据损坏）。修复照抄 `scn_tool.py add_unit`：`lastId = max(lastId, 全部 IdNum 数字后缀最大值)`，删除不回退；TrackNumber 走 `currentTrackNumber++`。
- **P1-C1：`FormationType` 键恒输出**（官方存档无此键，队形信息在 `Formations` 数组）；**不可移动单位（设施/参考点/浮标）恒输出 `Speed/Course/Range/Past/FutureWaypointArray`**（官方存档这些单位无运动键）。→ 破坏字节级兼容。修复：按 domain 条件序列化或加 TypeAdapter。
- **P1-C2：`player_settings.json` 是自造键**（ShowTracks/ShowArcs…），桌面 schema 是 `{"Player_Settings":{"File","Display_Options":{15 键},"PlayerName","Units"}}` → 该文件对桌面是无效文件。
- 键序正确性已验证 ✅：顶层/单位/Waypoint(12 键)/TextTags(9 键)/Sensor·Weapon(9 键)/Time/Turns 均与官方 2.3.9 一致；空数组写 `{}` 容错 ✅。

## 5. 引擎语义规范

### 5.1 回合状态机（✅ 与桌面一致）

三态：`DO_BEFORE`（规划中）→ Do 移动（只推进 `PositionTime`，Phase=2）→ `DO_AFTER` → Next 确认（`TurnTime` 追平，`Turns` 追加，Phase=0）→ 下一轮。Undo 仅 DO_AFTER 可用，恢复快照 + 回退 PositionTime。门禁 `canDo/canUndo/canNext` 在 UseCase 层。

缺陷：
- **P2-E5：Undo 用 `file.units.map{idNum}` 重建 `objects`** —— Objects 是桌面独立键（SaveObjects），会被摧毁；快照还漏 `@Transient ignoreRange`。
- **P3-E11：时间用字符串相等比较**（`tt==pt`），应统一 `TimeUtil.equal()`。

### 5.2 运动引擎（⚠️ 有意增强 + 若干偏差）

安卓 MovementEngine 实现的是**鱼叉 V 纸质规则**（前冲/45°分段/转向损失/0-75%·75-100% 加速档/急舵/新单位当回合不动），**桌面版 `CMovableUnit.Move` 本身无此模型**（仅匀速直航）——属有意偏离（README 已声明），但需要：

- **P2-E9：提供"桌面兼容模式"开关**，否则与桌面同场景对拍永远对不上；
- **P2-E4：Range 扣减规则不同**（安卓整数化且每回合至少扣 1 海里，低速短回合消耗远快于桌面）；
- **P3-E10：航路点归档阈值是启发式**（max(回合移动距离, 1nm)，且用回合末新航速估算，Range 截断回合会高估）；
- **P3-E8：到达时间丢秒**（`(hours*60).toLong()` 截断）。

### 5.3 编队引擎（❌ 两处实质偏差）

- **P1-E1：移动后不同步成员 Course/Speed**（桌面明确 `member.Course/Speed = center.*`）→ 成员轨迹、速度领导者、存档全部分歧；
- **P2-E2：RelativeToCourse 用标称站位（bearing+distance）重算**，桌面是旋转成员**实际偏移**——成员被拖离站位后行为不同；
- **P2-E12：`FormationEngine.cancel` 清空未来航路点**，桌面是**恢复原航路点**（prepare 需先备份）。

### 5.4 高度/深度（❌ 缺上限）

- **P2-E3：`applyAltitudeDepth` 无单回合 180 米上限**（advance() 注释声称有，实现没有，自相矛盾；桌面 asm 确认 180 常量）。

### 5.5 感知迷雾（✅ 语义正确，键序待对拍）

己方全见 / 无 Perception 记录全见 / 有记录按 `SeenBySide` 过滤 + 受限项脱敏（ShowName/ShowCourseSpeed/ShowClass/ShowAsType/ShowAsSide/ShowAltitude/ShowDepth）。落盘 Referee 全量、Blue/Red 剔除不可见。键序无真实样本验证（决策项 D1）。

### 5.6 回放（❌ 一处语义错误）

- **P2-E7：无轨迹的单位在所有帧显示当前位置**（第 5 回合新建的单位在第 1 回合回放也"存在"）。应按 PositionTimeCreated/Deleted 过滤。

### 6.3 方位角约定差异（⚠️ 需决策 D2）

桌面 `CalcBearing = ATan2(Δy,Δx)`（数学角 0=东逆时针，asm 已核实）；安卓 `CoordUtil.bearingDeg = atan2(dx,dy)`（罗盘角 0=北顺时针）。Bearing 不落盘，影响测量显示/CSV Bearing 列/被动方位/航路点方位显示。安卓约定更符合航海习惯，**建议保留并文档化**。

### 6.4 有意偏离桌面版清单（文档化，非 bug）

1. 鱼叉转向/加速规则（§5.2）；
2. 罗盘方位角（§6.3）；
3. 护航队阵位 0°=北顺时针（桌面 0°=东，环对称形态相同、具体舰位差 90°）；
4. CSV 数字格式 `%.1f/%.2f`（桌面 `####/#######.##`）。
