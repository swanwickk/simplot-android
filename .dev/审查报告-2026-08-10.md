## 4. 代码质量审查

### 4.1 与契约/报告不一致（中高风险）

#### 问题 A：`coder8-report.md` 与真实代码不符

报告声称：

> "**Slider 保留为辅助**（在输入框下方）：拖动实时更新 `course/speed` 并同步 `courseText/speedText`"

实际 `UnitEditSheet.kt` 中：

- 已经**完全删除 Slider**
- 注释写为 `反馈⑨：航向/航速纯数字输入（去掉滑杆，改为纯输入）`
- 报告版本 v0.3.8 四项修复，但代码明显混入了**未落盘契约的「反馈⑨/⑩/⑮/⑯/⑰/⑱」**大量改动

**影响**：报告不可信，后续维护者会被误导。

#### 问题 B：CWS 类型下拉选项与契约描述不符

`contract8.md` 要求「显示为类型」选项：

> `真实类型（留空）` + `BB/CC/DD/FF/PC/LA/LC/LS/AR/AS`

实际代码：

```kotlin
private val SHOW_TYPE_OPTIONS: List<Pair<String, String>> = listOf(
    "真实类型（留空）" to "",
    "BB" to "BB", "CG" to "CG", "CV" to "CV", "DD" to "DD", "FF" to "FF", "PC" to "PC",
    "LA" to "LA", "LC" to "LC", "LS" to "LS", "AR" to "AR", "AS" to "AS"
)
```

- 契约里的 `CC` 被替换为 `CG`
- 新增了 `CV`
- 去掉了 `CC/CL/CA` 映射（虽然 `UnitRenderer` 仍有 `CL/CA → CC` 别名，但下拉已无 CC 选项）

**影响**：用户选择「显示为类型」时，若选择 CG，需要确认 `UnitRenderer.CWS_CLASS_CELLS` 中是否存在 `CG` 映射。当前映射表没有 `CG`：

```kotlin
private val CWS_CLASS_CELLS = mapOf(
    "BB" to (1 to 2), "CC" to (1 to 3), "DD" to (1 to 4), ...
)
```

这会导致选择 `CG` 后，CWS 图标绘制时 `drawCwsIcon` 找不到映射，回退到矢量兜底符号——功能上不会崩溃，但用户期望的 CG 专属图标不会出现。

**建议**：
1. 统一 CWS 类型简称与映射表
2. 若精灵图确实无 CG 格，应移除下拉中 `CG` 选项或新增映射
3. 更新契约/报告以反映真实实现

## 5. 架构与模块审查

### 5.1 架构分层

- `MainActivity` 基本保持薄壳职责：SAF 回调 + Compose 组合 + 事件转发 ✅
- `GameViewModel` 持有全部 UI 状态与业务入口，职责清晰 ✅
- `ScenarioRepository` 负责文件 I/O，与业务逻辑分离 ✅
- `MovementEngine` / `FogOfWar` / `TurnState` 等纯 Kotlin object，便于测试 ✅

### 5.2 数据模型

`Unit.kt` 注释详尽，数值编码规则清晰：

- `Speed/Course = ×1000` 定点
- `X/Y = ×100000` 海里定点
- `Altitude/Depth = 米，原样存取`

但注意 `setCourse` 使用 `deg % 360`，而 UI 编辑使用 `coerceIn(0.0, 360.0)`。输入 361 时：

- UI 层先 clamp 到 360
- 再经 `setCourse` 取模后仍为 360

输入 360 与 0 在罗盘语义上等价，但存储值不同（360000 vs 0）。桌面版行为需确认。

### 5.3 渲染层

`UnitRenderer`：

- CWS 精灵图懒加载 + 缓存 ✅
- 加载失败打 Log + 矢量兜底 ✅
- `iconSizePx` 引入 density，真机显示更合理 ✅
- 速度领导线从图标边缘出发，避免遮挡 ✅

但 `drawCwsIcon` 注释说"CV 类改为代码绘制标准符号"，实际实现里并没有针对 CV 的特殊分支——仍然走精灵图裁剪（col1）。注释与代码不一致。

### 5.4 运动引擎

`MovementEngine`：

- 转向渐进式、Range 限制、编队移动、高度/深度变化均实现 ✅
- undo 快照深拷贝 ✅

注意：

- `range -= maxOf(1, distNm.roundToInt())`：Range 海里数扣减按 `roundToInt`，如果 `distNm = 0.4` 会被扣 1，可能偏快耗尽
- `formationDistance` 单位注释为"文件单位"，但代码中直接与中心坐标相加，未做换算，需确认与桌面版一致

### 5.5 SAF 文件保存

`saveThreeFilesTo()` 改为使用 `CreateDocument` 单文件选择器，再由目标文件 URI 推导父目录写 SpScn：

- 推导父目录逻辑 `parentTreeUri()` 合理 ✅
- 若父目录不可写，仅保存 Referee json，返回 false ✅
- 但旧接口 `saveThreeFiles()` 和 `savePerceptionAware()` 仍保留，MainActivity 已不再调用，成为**僵尸接口**

**建议**：清理不再使用的旧保存接口，避免维护负担。
